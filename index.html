Architecture & Integration

Built on a Vision Transformer backbone, fine-tuned for high-accuracy nuance detection across diverse datasets.

Ultra-Low Latency

Runs the selected Hugging Face image-classification model in your browser after the model is downloaded.

Hugging Face Ready

Loads cuplis123/facial_emotion_bgs through Transformers.js and keeps camera frames on this device.

Vision Transformer

The model returns emotion labels and confidence scores from each analyzed camera frame.

python 
from transformers import pipeline

# Initialize the emotion detection pipeline
classifier = pipeline("image-classification", model="cuplis123/facial_emotion_bgs")

# Run inference on a frame
results = classifier("live_frame_01.jpg")
print(results)
